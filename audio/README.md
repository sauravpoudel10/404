# Reel audio

Drop royalty-free `.mp3` / `.m4a` / `.wav` files here. One is picked at
random per Reel, trimmed to 7s with a fade in and out.

Leave this folder empty and Reels get a silent audio track instead — which
is fine, just quiet.

## Where to get tracks you're actually licensed for

**Meta Sound Collection** (recommended) — free, and explicitly licensed for
business accounts on Instagram and Facebook. Download from Meta Business
Suite. This is the safe default.

## What not to use

Commercial/chart music. Instagram's music catalogue is not reachable through
the publishing API at all, and a copyrighted track baked into the file gets
the Reel auto-muted or removed by Content ID — and the same video also goes
to X, which runs its own detection. It's the account that takes the hit.
