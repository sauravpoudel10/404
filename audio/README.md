# Reel audio

`beat-*.mp3` are generated by `tools/make_beds.py` -- synthesised from
scratch (chord progression, kick, hats, bass, arpeggio), so no third-party
rights are involved. One is picked at random per Reel, looped to 7s with a
fade in and out.

Regenerate or retune them with:

```bash
python tools/make_beds.py
```

## Using your own music instead

Drop any `.mp3` / `.m4a` / `.wav` in here and it joins the rotation --
delete the `beat-*` files if you want only yours.

**Meta Sound Collection** is the safe source: free, and explicitly licensed
for business accounts on Instagram and Facebook. Download from Meta
Business Suite.

## What not to use

Commercial or chart music. Instagram's own catalogue is not reachable
through the publishing API at all, and a copyrighted track baked into the
file gets the Reel auto-muted or removed by Content ID -- the same video
also goes to X, which runs its own detection. The account takes the hit.
